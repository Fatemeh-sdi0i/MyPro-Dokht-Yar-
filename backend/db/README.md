# دیتابیس دوخت‌یار (PostgreSQL)

- `migrations/` — مهاجرت‌های شماره‌دار SQL. هر فایل یک‌بار و در یک تراکنش اجرا می‌شود.
- `migrate.sh` — اجرای مهاجرت‌ها (`DATABASE_URL=... ./backend/db/migrate.sh`).
- `test/schema_test.sh` — آزمون قواعد یکپارچگی روی یک پایگاه موقت (`ADMIN_URL=... ./backend/db/test/schema_test.sh`).

قواعد کلیدی:
- شماره‌ی تماس مشتری در هر مزون یکتا است، اما فقط برای رکوردهای فعال (بعد از حذف نرم دوباره قابل ثبت است).
- شماره‌ی سفارش در هر مزون یکتا است؛ هنگام ثبت باید داخل تراکنش و با قفل روی ردیف `shops` محاسبه شود.
- مبالغ به تومان (`bigint`)، زمان‌ها `timestamptz` و تاریخ‌های روزانه `date` (میلادی). نمایش شمسی در رابط کاربری انجام می‌شود.
- هر به‌روزرسانی `version` را یک واحد افزایش می‌دهد و `updated_at` را تنظیم می‌کند.
