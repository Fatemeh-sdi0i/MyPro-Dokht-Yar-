دوخت‌یار - نمونه اولیه رابط کاربری

روش اجرا:
1) فایل ZIP را Extract کنید.
2) وارد پوشه dokhtyar-ui شوید.
3) فایل index.html را با Chrome یا Edge باز کنید.

این نسخه یک prototype فرانت‌اند است و اطلاعات در حافظه مرورگر/کد نمونه نگهداری می‌شوند؛ هنوز به پایگاه داده یا سرور متصل نیست.
صفحات خانه، سفارش‌ها و مشتریان پیاده‌سازی شده‌اند. بخش همکاران، امور مالی، گزارش‌ها و تنظیمات فعلاً جایگاه اولیه دارند.
برای تبدیل به PWA و اتصال به بک‌اند باید در مرحله بعد manifest، service worker و API اضافه شوند.
