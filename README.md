# دوخت‌یار — نمونه اولیه‌ی رابط کاربری

رابط کاربری مدیریت مزون و خیاطی «دوخت‌یار». این نسخه یک برنامه‌ی **استاتیک (HTML/CSS/JS بدون وابستگی و بدون مرحله‌ی build)** است.

## وضعیت فعلی (فاز ۱)

| بخش | وضعیت |
|---|---|
| خانه (داشبورد، ثبت سفارش سریع، تحویل‌های نزدیک) | ✅ |
| سفارش‌ها (جستجو، فیلتر، تغییر وضعیت) | ✅ |
| مشتریان (جستجو، جزئیات، افزودن مشتری) | ✅ |
| همکاران، امور مالی، گزارش‌ها، تنظیمات | ⏳ جایگاه اولیه (در فازهای بعد) |
| ذخیره‌سازی | ❌ داده‌ها در حافظه‌ی صفحه‌اند و با بارگذاری مجدد برمی‌گردند |
| PWA / سرویس‌کار (Service Worker) | ⏳ فاز بعد |
| بک‌اند و پایگاه داده | ⏳ فاز بعد |

## اجرای محلی

راه اول — مستقیم:
۱. فایل `index.html` را در Chrome یا Edge باز کنید.

راه دوم — با سرور محلی (توصیه‌شده):
```bash
python3 -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید.

## استقرار روی GitHub Pages

۱. این مخزن را در GitHub منتشر کنید (شاخه‌ی `main`).
۲. در **Settings → Pages** مقدار **Source** را روی **GitHub Actions** بگذارید.
۳. هر push به `main` از طریق `.github/workflows/pages.yml` به‌صورت خودکار منتشر می‌شود.

## ساختار پوشه‌ها

```
index.html        صفحه‌ی اصلی و ساختار تمام صفحات و مودال‌ها
css/styles.css    استایل‌ها (RTL، فونت وزیرمتن، واکنش‌گرا)
js/data.js        داده‌ی نمونه و توابع کمکی (اعداد فارسی، escape، شماره سفارش)
js/app.js         منطق رابط کاربری و رویدادها
.github/workflows/pages.yml   استقرار خودکار روی GitHub Pages
```

## تغییرات فاز ۱ نسبت به نمونه‌ی اولیه

- ساختار پوشه‌ها برای توسعه و استقرار (`css/`, `js/`, workflow)
- جلوگیری از تزریق HTML: تمام داده‌های وارد‌شده توسط کاربر هنگام نمایش escape می‌شوند
- شماره سفارش جدید بر اساس بیشترین شماره‌ی موجود ساخته می‌شود (قبلاً ممکن بود تکراری شود)
- نام ماه در «تحویل‌های نزدیک» از تاریخ واقعی گرفته می‌شود (قبلاً همیشه «آبان» بود)
- شمارنده‌ی «مشتریان کل» از داده‌ها محاسبه می‌شود (قبلاً عدد ثابت ۴۵ بود)
- فرم ثبت مشتری: اعتبارسنجی شماره‌ی موبایل ۱۱ رقمی
- بستن مودال با کلید Escape و پاک‌شدن فرم هنگام بستن
- اتصال رویدادها با delegation (بدون اتصال مجدد listener بعد از هر رندر)
- نوار پایین موبایل: همه‌ی ۷ بخش اکنون قابل دسترسی‌اند (قبلاً بخش‌های ۵ به بعد پنهان بودند)
- اصلاح یک قاعده‌ی CSS نامعتبر (`font: inherit`)

## نقشه‌ی فازها

- **فاز ۱ (این نسخه):** مخزن قابل استقرار، رفع مشکلات رابط، GitHub Pages
- **فاز ۲:** تکمیل بخش‌های همکاران، امور مالی، گزارش‌ها و تنظیمات + ذخیره‌ی محلی (localStorage)
- **فاز ۳:** PWA — manifest، Service Worker، آیکون‌ها، کار آفلاین
- **فاز ۴:** بک‌اند و API، پایگاه داده، احراز هویت

## محدودیت‌های شناخته‌شده

- داده‌ها ذخیره نمی‌شوند؛ با بارگذاری مجدد به حالت نمونه برمی‌گردند.
- تاریخ‌ها به‌صورت متن وارد می‌شوند و اعتبارسنجی تقویمی ندارند.
- ارقام نمایشی داشبورد (تحویل‌شده، در حال دوخت و…) هنوز ثابت‌اند.
